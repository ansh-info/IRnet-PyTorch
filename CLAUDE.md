# CLAUDE.md

## Project

IRnet Reproduce -- PyTorch + PyG reproduction of [IRnet](https://github.com/yuexujiang/IRnet) (pathway-informed GNN for immunotherapy response prediction).

## Quick Start

```bash
uv sync
uv run python run.py info

# Phase 1: Pre-train on TCGA
uv run python run.py --data-dir data train --epochs 400 --output checkpoints/pretrain

# Phase 2: Process clinical cohorts + fine-tune
uv run python scripts/prepare_clinical.py --data-dir data --all --output-dir data/clinical/
uv run python run.py --data-dir data train --npz data/clinical/clinical_Gide.npz \
    --pretrained checkpoints/pretrain/fold_0_best.pt --output checkpoints/finetune_gide

# Predict + Explain
uv run python run.py --data-dir data predict --input data/example_expression.txt --checkpoint-dir checkpoints/finetune_gide --output results/
uv run python run.py --data-dir data explain --input data/example_expression.txt --checkpoint-dir checkpoints/finetune_gide --output results/
```

## Architecture

- `src/irnet/data.py` -- Data loading, KEGG graph construction, z-score normalization
- `src/irnet/model.py` -- PathwayMappingLayer (sparse bio-constrained), GATConv x2, GlobalAttention, FocalLoss
- `src/irnet/train.py` -- 5-fold stratified CV, bootstrap balancing, early stopping, ensemble inference
- `run.py` -- CLI: train, predict, explain, info
- `scripts/prepare_clinical.py` -- Convert raw clinical cohort data (counts + labels) to npz format

## Key Concepts

- 8080 genes mapped to 344 KEGG pathways via biologically-constrained sparse layer
- Pathway interaction graph (3152 edges) processed by Graph Attention Network
- Only ~33K trainable params (98.8% reduction from dense)
- Focal loss (gamma=2) + bootstrap oversampling for class imbalance
- 2-phase training: TCGA pre-train (pseudo-labels) → clinical fine-tune (real ICI response)

## Data

All data sourced from [original IRnet repo](https://github.com/yuexujiang/IRnet):

- `data/genelist_8080.txt` -- fixed gene ordering (DO NOT reorder)
- `data/Kegg/human_KeggPathwayGene.gmt` -- pathway-gene membership (GMT format)
- `data/Kegg/human_KeggPathwayNet.txt` -- pathway-pathway interactions
- `data/example_expression.txt` -- example input (121 patients)
- `data/training files/*.npz` -- TCGA pre-training data (SKCM 435 + BLCA 389 + STAD 338 = 1162 patients)
- `data/Gide/`, `data/Liu2019_Melanoma_RNAseq/`, `data/IMvigor210/`, etc. -- clinical cohorts for fine-tuning
- `data/clinical/*.npz` -- processed clinical cohorts (generated by scripts/prepare_clinical.py)

## Reproduction Steps

1. Phase 1: `uv run python run.py --data-dir data train --epochs 400 --output checkpoints/pretrain`
2. Process: `uv run python scripts/prepare_clinical.py --data-dir data --all --output-dir data/clinical/`
3. Phase 2: `uv run python run.py --data-dir data train --npz data/clinical/clinical_Gide.npz --pretrained checkpoints/pretrain/fold_0_best.pt --output checkpoints/finetune_gide`
4. Predict: `uv run python run.py --data-dir data predict --input <expression.txt> --checkpoint-dir checkpoints/finetune_gide`
5. Explain: `uv run python run.py --data-dir data explain --input <expression.txt> --checkpoint-dir checkpoints/finetune_gide`

## Conventions

- PyTorch + PyG (not TensorFlow)
- Type annotations on all functions
- Immutable data containers (NamedTuple)
- No notebooks -- all .py files
- uv for package management
